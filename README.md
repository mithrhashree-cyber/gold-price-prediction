# Gold Price Prediction using Python and AI

## Project Overview

Gold Price Prediction using Python and AI is a project focused on understanding and analysing gold price movements using historical data and economic factors.

The project aims to explore how factors such as inflation, interest rates, US dollar strength, crude oil prices, currency exchange rates and global events influence gold prices.

## Objectives

- Understand the factors affecting gold prices.
- Analyse historical gold price data.
- Learn data analysis using Python.
- Explore machine learning techniques.
- Develop a model to predict gold price trends.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Machine Learning

## Project Status

Currently in the initial learning and setup phase.
